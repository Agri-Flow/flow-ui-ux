Spec

Build commentary only. Nothing on this rail is product copy — a warehouse clerk never sees any of it.

re: Screen

Tablet-first — the target device is a warehouse-floor tablet, so tap targets and the two-column split are sized for that first, desktop second.

re: Supplier

Options come from the Epic 2 supplier registry, filtered to active + verified. Suspended and soft-deleted suppliers are never selectable here.

re: Product / SKU

Sourced from Product Master (Epic 3). The SKU record carries the storage type and shelf-life that the expiry calculation depends on — this screen never stores its own copy.

re: Received weight

Two-decimal KG precision is the RSB measurement standard, not a UI preference. Validate server-side as a positive number, scale 2.

re: QC inspection

Grade bands are aligned to RICA produce grading. Reject routing to quarantine is programmatic — the client must not be able to place a rejected batch into sellable stock.

re: QC inspection › Reject

The reason-code and photo-evidence panel is designed on its own canvas — e4-batch-rejection-evidence.html.

re: Record Batch

Emits receiving.batch_created into the append-only audit_logs table. Submit is blocked while offline; the local draft is the only persistence until then.

re: System-computed

Every value in this panel is derived server-side at submit. Render read-only; do not accept a client-supplied value for any of them.

re: Traceability ID

Format [Date]-[SupplierID]-[SKU]. A same-day repeat from the same supplier and SKU gets a -02 suffix server-side — the collision is resolved silently and never surfaced to the clerk.

re: Expiry date

Received date + the SKU's shelf-life for its storage type. There is deliberately no expiry input on this form; a manually supplied date is refused by the server.

re: Storage type & shelf-life

Read from Product Master (Epic 3). Expiry drives FIFO allocation downstream, so it is never derived from the receipt date alone.

re: Compliance footer

Provenance for the rules above: weight precision follows the RSB measurement standard, grading follows RICA produce grading, and audit retention follows Rwanda FDA Law N°003/2018.
