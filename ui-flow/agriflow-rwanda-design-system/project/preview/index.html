The AgriFlow Design System

The visual contract for AgriFlow Rwanda — a B2B fresh-produce platform reducing post-harvest food loss across 18 districts. This page collects every foundation (color, type, spacing, radii, shadows) and every primitive (buttons, pills, inputs, tables) the product uses, in one scrollable view. The live React kit is one click away; the static HTML prototypes that production code mirrors live in ui-flow/.

Foundations · Color

Color system

A focused 10-step green ramp anchored on #1B8C4E (the brand), a neutral gray ramp for text and surfaces, and four semantic tone pairs (success, warning, danger, info) that drive every status pill, alert, and badge across the platform.

Primary — Green ramp
Open ↗
Step 500 (#1B8C4E) is the brand anchor — every CTA, active state, primary icon, and progress fill. 50–200 are surface tints; 600–900 are pressed and dark-mode anchors.
Neutral — Gray ramp
Open ↗
Text emphasis ramp (fg-1 → fg-6) and surface plates derive from these. Never use raw hex — reference var(--fg-3) etc.
Semantic tones
Open ↗
Success / warning / danger / info — each as a fg + bg pair. Drives status pills, alerts, FDA badges, and table-row tints.
Surface plates
Open ↗
Three flat layers: page (#F0F2F5), card (#FFFFFF), brand-tint accent (#F3FAF6) for hovers and "info" callouts.
Foundations · Type

Typography scale

Inter for everything except eyebrows and monospaced data (timestamps, IDs, account numbers) which use a mono fallback. Headings carry a slight negative tracking; eyebrows are tracked-out caps.

Display headings
Open ↗
Page titles and dashboard hero stats. Used sparingly — 24 px Bold for top-level dashboards only; in-app pages use 20 px Semibold.
Body
Open ↗
14 px base. Three weights cover 95% of needs: 400 paragraph, 500 emphasis, 600 navigation / table cells.
Eyebrow / mono
Open ↗
10–11 px uppercase tracked labels for section headers and field eyebrows. Monospaced 12 px for SKU codes, audit references, account numbers — anything that should be readable as data.
Foundations · Layout

Spacing, radii & elevation

A 4 px grid for spacing, four radii steps (6 → 12 px) for components, and four shadow steps for elevation — from a barely-there card lift to a pop-out menu.

Spacing scale
Open ↗
4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 48 / 64 px. Tailwind p-*, gap-*, and m-* resolve to these.
Radii
Open ↗
6 / 8 / 10 / 12 px. Cards use 12, buttons / inputs 10, badges 6.
Shadows
Open ↗
Card / pop / sidebar / button — four directional steps for the AgriFlow elevation language.
Logo & brand mark
Open ↗
Tilted-almond leaf with a diagonal vein. Pure green silhouette on white lockups; white silhouette on the brand-green tile. Reserved variants documented in the preview.
Components · Form & input

Buttons, inputs & selects

Every control settles at 40 px tall (login primary is 44 px) for consistent touch / pointer ergonomics. Selects use a custom popover styled to match the row-action menu pattern.

Buttons
Open ↗
Primary (brand green, white text), Secondary (white, neutral border), Ghost (no background, brand text), Danger (deep red), Disabled (gray plate). Three sizes — small (32 px), default (40 px), large (44 px) for hero CTAs.
Text inputs
Open ↗
Default, with leading icon, with country prefix, and error / focus states. 40 px tall, 10 px radius, 13 px inner text.
Select
Open ↗
Closed and open states. The open popover uses a green checkmark on selected, hover-row tint, and matches the row-action menu chrome so the language reads consistently.
Components · Data display

Cards, pills, tables & alerts

The building blocks of every list and detail screen — kept deliberately spare so the data (not the chrome) carries the page.

Card
Open ↗
White plate, 12 px radius, 1 px hairline border, soft card shadow. Sections inside use 22 px inner padding; stat cards use 18 px.
Pills & badges
Open ↗
Role pills use single-hue brand (locked decision — no multi-color per role). Status pills are tone-mapped to the semantic palette: success / warning / danger / info.
Avatars
Open ↗
Circular initials. Brand-tint background by default; status dot overlay for "is active now".
Alerts
Open ↗
Inline banners for state-of-the-record (suspended supplier, expired RICA, unsaved changes). Always include a tone-colored icon and a follow-up action where applicable.
Table
Open ↗
Title-case headers (12 px / 600 / muted), top border so the header band reads as contained, brand-tint hover, right-aligned numerical columns, 44 px actions slot.
Pagination
Open ↗
"Showing X–Y of Z" left, 32 px numbered buttons right. Active page uses brand-tint, not a hard fill.
Sidebar row
Open ↗
A single nav row anatomy: icon + label, optional badge / submenu chevron. Active leaf uses soft brand-tint; parents that own an open submenu use brand text + bold without a fill.
