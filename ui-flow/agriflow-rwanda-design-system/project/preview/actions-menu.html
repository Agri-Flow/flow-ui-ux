Component · shadcn/ui Popover + DropdownMenuItem

Actions Menu

Vertical-kebab trigger that opens a shadcn Popover containing a list of DropdownMenuItems. Use it on cards, list rows, and detail headers when more than two actions need to live near a record without crowding the layout. Destructive actions appear last, separated by a DropdownMenuSeparator.

Anatomy

  1. 1
    PopoverTrigger: 36×36 icon button with vertical kebab. Toggles data-state between closed and open; styled to invert to bg-accent while open.
  2. 2
    PopoverContent: 280px wide, bg-popover, 1px border, shadow-md, 4px inner padding. Anchored with data-side="bottom" + data-align="end".
  3. 3
    DropdownMenuItem: 16×16 icon + label, full-row hit area, hover/focus uses the shadcn pattern focus:bg-accent focus:text-accent-foreground.
  4. 4
    Separator + destructive variant: DropdownMenuSeparator precedes any item with data-variant="destructive"; the variant uses text-destructive with a tinted hover.

Implementation (flow-fe)

In flow-fe, render this with the shadcn primitives — typically DropdownMenu (which is built on Radix Menu, exactly this pattern). If the trigger needs richer content than a button, swap to Popover with Command inside.

    <Button variant="outline" size="icon" aria-label="More actions">
      <MoreVertical className="size-4" />

Usage

Do

  • Use for 3+ secondary actions on a record.
  • Place destructive actions last, separated by a DropdownMenuSeparator.
  • Anchor with align="end" so the panel hugs the trigger's right edge.
  • Keep labels to one line; truncate or move to a side panel for longer copy.

Don't

  • Don't bury the primary action of a screen inside this menu.
  • Don't mix navigation links with actions; use a sub-page for navigation.
  • Don't show more than 6–7 items — split into sections or a side sheet.
  • Don't apply data-variant="destructive" on non-destructive items.
